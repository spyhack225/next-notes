    Paced authored-fixture runtime replay

    • hardware: Apple M3,16GB RAM
    • os: macOS27.2 build26B5091g
    • workload: Normal desktop apps; coordinated serial window with no concurrent native build/model job. Existing swap/desktop pressure retained in per-model context; no concurrent voice qualification.
    • power_thermal: Per-model power/thermal/load/swap observations retained. Cold preparation is separate from warmed timing.

    Limitations

    Authored PCM replay exercises the app engine, scheduler and transcript consumer; physical microphone, UI insertion, cleanup and concurrent voice remain unverified.

    Short-excerpt latency and full-fixture accuracy are separate measurements; this is not whole-app dictation latency.
