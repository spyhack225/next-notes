# P3-01: voice regressions exercise production — 2026-10-01

Voice tests now enter `RealtimeAgent.handle(.voice)` → `VoiceConversationCoordinator`
with a scripted frontend and scripted **worker provider**, while the real planned
worker, tool runner, capture endpoint, task ledger and output delivery execute.
The fake external executor needs no microphone, model weights or account.

## Confirmed causes and fixes

The old routing producer selected a legacy voice branch whenever the shared typed
provider override was set. Capture also called `appendVoiceFollowUp`, whose guard
made it unreachable in production. The installed old-route regression now fails
with `typed provider override rerouted voice away from coordinator`.

Voice handle, speech onset and discarded input now use the coordinator regardless
of that typed override. The dead follow-up method and its sole call are deleted.
A harness voice request without a frontend fixture fails closed, printing
`VOICE_LEGACY_PATH_REACHED`, except for the five audited registered real-model
voice probes. Typed planner/local-answer paths remain intact. The new coordinator
worker-provider seam is reset with the other fixtures; it replaces only the model,
not `runVoiceObjective` or the tool loop.

Ported regressions cover an independently parked worker during side conversation,
explicit capture cancellation and its actual cancelled task-ledger row, stale
answer suppression, capture-driven correction with unchanged identity/revision
and retained reads, an unspeakable listing with its full written result, no-tool
frontend prompt/route, first-clause streaming and interruption. Typed explicit
local-model tests retain provider/history/timeout checks; separate coordinator
voice streams preserve first-clause and unsafe URL/code speech assertions. A
held-floor correction checks identity/no cancellation/revision without forbidding
background progress while the person speaks.

Two other producer failures were found during baseline verification:

- **Budget refill sign:** the planner passed `remaining - oldRemaining` into
  `ToolStepRunner.charge`, which subtracts elapsed time. A refill therefore removed
  time. The call now charges `oldRemaining - remaining`. The original real-worker
  correction fixture is red before and green afterward with the same 2 s round,
  1 s read, 3 s ceiling and 10 s refill interval. No limit or throttle changed.
  The negative refill case uses the current timeout renderer sentence instead of
  an obsolete `too long` substring; duplicate failure reporting was removed.
- **Implicit TTS warmup:** constructing the synthesizer eagerly started the selected
  Pocket engine before scripted tests could install their recorder. The baseline
  delivery test hit `LLVM ERROR: ... No space left on device` during CoreML loading.
  Scripted harness startup now skips that implicit engine warmup; explicit real
  speech probes still prepare their engine, and normal app startup is unchanged.
  Completed owned dictionary compiler output was reclaimed; no owner models were
  removed, downloaded, copied or hashed. Installed delivery then passed.
