## Display and appearance contract found in code

- The main window minimum is **900 × 600 pt** (`DS.Size.windowMin`, `MainWindow`). Onboarding has its own **720 × 600 pt** fixed starting size (`DS.Onboarding.window`, `OnboardingWindowController`). Their minimum-size screenshots were **not** captured here.
- `IslandGeometry.notchWidth(of:)` requires both top safe-area inset and auxiliary menu-bar areas. `metrics(for:)` hugs a notch with an opaque black substrate and white ink; otherwise it places a glass capsule below the visible menu bar with semantic ink. `IslandPanel` follows the pointer’s display, stays at expanded window bounds, ignores clicks while collapsed, and hit-tests only the island rectangle while expanded. No physical notch or external monitor was inspected in this audit.
- The panel stays nonactivating, one level above the status bar, in all spaces and full screen auxiliary spaces. `cardIdentity` prevents audio-level changes from restarting the panel transition. The orb/avatar badge is wrapped in an equatable view so level ticks do not remount its animation.
- `ThinkingOrb` and `AgentAvatarView` read Reduce Motion; `GlassSurface` has a Reduce Transparency fallback. `IslandView` uses a spring and `keyframeAnimator` for expansion, and onboarding uses `.transition(.opacity)`, without a local Reduce Motion branch in those containers. This is a **review target**, not a claim that macOS fails to honor the setting. `IslandView` and `HUDView` directly call `.glassEffect`; verify their readability with Reduce Transparency on, especially on a floating display.
- `DS.Color.record` is the recording red; the island badge keeps that red dot beside the orb/avatar, and the HUD keeps a real level bar. The agent character and app orb encode different states; one screen should have only one active live mark. `IslandState.Kind.orb` currently names `.agentProposal` as `searching`, while `IslandState.avatarState` renders a `waiting` avatar for it; the actual avatar wins in `IslandView`. UX-01 should document that precedence rather than retune the orb for appearance.

## Event-source and evidence checklist for the live capture

| Moment to capture | Producer / consumer to timestamp | Expected visible proof |
|---|---|---|
| Hold begins | `DictationController` state/capture → `NextNotesApp.observeState` or `IslandState.liveKind` → panel | Red recording dot and live level, without stealing the target app’s focus. |
| Hold ends and text arrives | `DictationController` finishing/transcript → `HUDView` or `IslandView` → `TextInjector` | Recording dot ends; work label is honest; text lands at the captured target. |
| Agent hears and works | `AgentCaptureController`/`ActivationController`/`AgentActivityStore` → `IslandState.refresh` → `IslandPanel.apply` | Saved face with the correct state, short real work step, Stop available. |
| Approval is needed | `PermissionGate.pending` and `queuedCount` → `IslandState.livePendingApproval` → notice/persistent badge | Exact request opens in the main window when the compressed card cannot carry it; no second gate. |
| Meeting is armed/recording/finished | `MeetingScheduler`/`MeetingController`/`NotesService` → `IslandState` | Record/Skip when armed; two-track recording signal; notes result opens the real meeting. |

For each, record a short non-sensitive movie and stills in **light and dark**, at the **900 × 600 pt** main-window minimum and a larger size. Include notched and floating displays if actually available. Note `t_event`, `t_state`, and `t_first_visible_frame`; report deltas instead of guessing them from animation constants. Repeat with keyboard, VoiceOver, Reduce Motion, and Reduce Transparency. If a display, grant, model, or account is absent, mark that row **unverified**.

## Suggested UX-01 handoff

Freeze a one-page map using the components above: **semantic system shell and type; one active character for agent work or one active orb for app work; still badge for blocked approval; red dot plus level for recording; glass only where it bounds a decision or result.** Reuse `DS.Motion` and existing spacing/material tokens. Add a token only for a measured need in a concrete view. Before changing island animation, test Reduce Motion expansion and pending-approval focus/hover on both substrates. Keep the website loop as an optional guided preview, never as a production activity signal.
