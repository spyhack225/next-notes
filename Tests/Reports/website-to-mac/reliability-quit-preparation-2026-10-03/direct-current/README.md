## Source contract and limits

Current `ParakeetEngine.finish()` cancels and captures its existing partial Task, then awaits that Task before final transcription. The first direct producer gap is that `DictationController.cancelDictation()` creates a finish Task and forgets it; the ordinary timeout path can similarly leave a retired native Task after its RaceGate result. Its fixed candidate retains the same chain and closes at quit. The next producer gap, after that prerequisite, is `ParakeetEngine.feed()` accepting samples after `finish()` has started but while its actor is suspended. A new uncancelled partial can escape the captured handle; the late fixed candidate closes input before the first existing await and reopens only for a current, uncancelled start. No new store, queue, fixed sleep, native model pass, normal turn await or global cancellation owner is introduced.

The AppDelegate currently calls `controller.deactivate()` at `applicationWillTerminate`, too late to own native work at the quit proposal. Direct COMMON routes `beginTermination()` at `applicationShouldTerminate` before its existing asynchronous drain and calls `finishTermination()` within that drain; only the fixed Controller actually retains the retired owner for those calls to join. The current post-ASR Controller tail checks `self.session == session` before cleanup, after cleanup, and before `recordRun`/insertion; it checks again after insertion. Quit cancellation increments the session and should therefore refuse that tail when those guards are reached. This packet's native fixture, however, deliberately supplies no audio to the **current** result and uses zero-output sinks. It does not verify a healthy spoken tail, typed text, physical capture, or post-insert effect. `ChunkedFormatter` in `SentenceChunker.swift` substitutes its raw group when an inner formatter returns empty, so the separate S1 formatter empty-result candidate cannot be used as whole-dictation stale-delivery proof. No consumer fallback or timeout was rewritten here.

The recorded **5.8 s against 5 s** failure in `--selftest-model-unopenable` is the inner `NotesModelRuntime` S1 trial with an eight-token cap. This direct Parakeet proposal concerns controller-owned ASR tasks; the S1 cleanup cancellation packet concerns `S1MiniRuntime.normalize`. Neither explains that 5.8 s measurement, the original SIGSEGV, or full safe and fast process quit. Pending start/feed continuations, old callbacks, physical audio, package-internal native work after public return, and model quality remain open. No release or installation follows from this packet alone.
