## S1 formatter cancellation

The frozen packet at `manifest.json:frozenS1Packet` matches the current `S1MiniFormatter.swift` and `NativeOtherLlamaQuitSelfTest.swift` preimages exactly. `s1-common.patch.txt` and `s1-producer.patch.txt` are byte-identical copies of its relative patches, retained here for a single handoff. The common patch adds private, default-nil fixture selection, actual native-return observation, and three modes. The fixed patch changes only `S1MiniFormatter.swift`: one synchronous termination admission flag on the existing runtime actor, cancellation checks at native-return/loop boundaries, and no rules fallback for a cancelled caller or closed runtime. Its 30 checks (11 cancel, 11 stop, 8 genuine error) are **proposed and unrun**. Actual native EOS timing may invalidate the original comparison. The public model remains the source-pinned S1 GGUF: 484219808 bytes, SHA-256 `3b41ebe2502cbd03e811d5d16b022f5ab551eda58d62597d152f89535003c634`; root's existing confined clone/digest guard is required.

There is a distinct **product quit entry gap**. Current `AppDelegate.applicationShouldTerminate` selects `s1` before creating its quit Task but calls only `await s1.finishTermination()` *inside* that Task. If the S1 actor is executing its synchronous decode loop, that actor call cannot publish stop until the loop returns. `s1-app-quit-entry-candidate.patch.txt` places `s1.beginTermination()` at the existing synchronous delegate entry after selecting the same runtime, leaving native release on the same actor in `finishTermination()`. It is a separate candidate, **held from release**: the frozen S1 stop fixture calls `runtime.beginTermination()` itself after two real native returns, then requests Cocoa quit only after joining the formatter. It does not exercise the AppDelegate entry hunk. A qualified original/fixed Cocoa quit regression must observe the actual delegate calling the synchronous stop while the same formatter operation is active, prove no later native entry and no stale delivered result, and preserve the current veto/recording/Notes/other-owner paths. No UI or consumer substitute establishes this.

### Additive actual Cocoa-entry candidate

`s1-cocoa-common-after-frozen.patch.txt` applies **after** the byte-identical frozen COMMON patch. It adds only one mode, `s1-cocoa-format`, in the existing confined other-llama standalone route. It extends the frozen S1 fixture-selection predicate to permit the same default-nil private runtime injection and adds `NativeS1FormatterCocoaQuitSelfTest.swift`. The original three frozen modes, authored inputs and public asset validation are untouched. The new mode uses the frozen native-return callback after exactly two successful, balanced real `llama_decode` calls. A fixture-only `NSCondition` holds that *returned* Swift callback while `RunLoop.main.perform` requests real `NSApp.terminate`; the actual `AppDelegate.observedTerminationReply(.terminateLater)` releases the gate. Its ten-second bound makes a missing reply invalid rather than an unbounded hang. It never holds an entered C call or adds a product wait. If the runtime executes the callback on the main run-loop thread, the bound expires and the run is invalid; this must be measured.

At the first actual delegate reply, the control requires two successful returned decodes, zero active native brackets, the same formatter Task pending, and the real `.terminateLater` reply. The delegate has already reached the synchronous S1 stop point on the fixed side. After the callback is released, F01 compares native starts with the first reply count; F02 checks the returned formatter string is empty before process exit. The existing delegate `finalReply` can veto an in-flight formatter and its existing `safetyDrain` awaits that **same** retained operation before re-quit. No fixture waiter Task or extra native owner is introduced. Any missed callback/reply/overlap, timeout, model input failure or unbalanced bracket is INVALID, never a producer RED or GREEN. The exact check count and red/fixed verdict are **unrun**.

`s1-cocoa-fixed-after-common.patch.txt` combines the frozen S1 producer delta with the separate synchronous AppDelegate quit-entry hunk; the original side receives neither fixed producer hunk. Apply only after both COMMON patches against their pinned preimages. Root must run original first with the same new mode and public GGUF copy, then fixed, while retaining actual first-reply and final-exit traces and the old 30-mode results. Keep the native process watchdog, source/bundle identity and source-pinned model digest checks. This candidate remains **uncompiled, unrun and held** pending root's serial review and measurement; text patch construction and applicability do not establish success.

For the frozen three-mode packet, root must first get qualified original RED, then the same fixed inputs GREEN, with actual count/exit/trace controls and the existing 49 other-llama cases plus relevant cleanup/dictation checks. These tests only cover cooperative boundaries after a native call returns, not interruption of an entered C kernel, full quit safety, or typing delivery. `ChunkedFormatter` may still preserve a raw piece when an inner formatter returns empty.
