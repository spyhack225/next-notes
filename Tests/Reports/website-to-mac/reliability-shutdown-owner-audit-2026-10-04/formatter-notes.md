# Formatter and Notes shutdown owners: current source audit

**Source-only, 2026-10-04. No implementation, compiler, model, native or installed-quit run.** `formatter-notes-pins.json` records the exact source bytes and line anchors. The frozen `direct-rebase` packet remains unchanged. This audit describes the current producer/owner contracts and the acceptance still missing; it is not evidence that a quit crash has been reproduced or fixed.

## Actual entry and order

`NextNotesApp.swift:9635–9750` is the AppKit `applicationShouldTerminate` path. A repeat request while `nativeTerminationTask` exists returns `.terminateLater`. A recording first receives its one Stop and Quit choice; rejection returns `.terminateCancel`. The delegate then synchronously captures/cancels `NotesService` tasks, closes `FinalTranscriptService` and `DiarizationService`, calls `PocketAgentVoice.beginTermination`, captures loaded model/library owners, and calls `InstalledModelLibrary.beginTermination`. It assigns one MainActor termination `Task` and returns `.terminateLater` (`9636–9697`).

Inside that task, `NotesModelRuntime.beginTermination` is the **first await**, followed by queue/diarizer/parakeet closure, then `S1MiniRuntime.finishTermination`, `EmbeddingRuntime.finishTermination`, captured model tasks/library completion, and `LlamaBackend.beginTermination`. Recording stop has an existing bounded call. The task joins captured NotesService work and the other queues, finishes the Notes runtime, then replies to AppKit. `drained` and every configured diagnostic final-reply veto must be true; the same one-shot diagnostic safety drain follows a false reply only when the real drain succeeded (`9696–9746`). `applicationWillTerminate` cannot await; it deactivates dictation, ends the meeting, and synchronously stops the Needle child (`9749–9766`). The delegate itself says a SIGTERM/install-script path does not invoke this asynchronous drain (`9630–9634`).

The standalone native harness validates private arguments before constructing its AppDelegate, runs a concrete AppKit application and calls the same delegate methods (`NativeTerminationSelfTest.swift:8–38`; `NextNotesApp.swift:458–464, 866–873`). Its Notes case injects a confined GGUF, isolated `NotesService`/`NotesModelRuntime`, and a real summarize task. It checks an entered decode bracket, captured task, `.terminateLater`, returned brackets, no generated notes, and resumable `.summarizing` status (`NativeTerminationSelfTest.swift:63–151`). The other-Llama harness selects separate S1, embedding, library or probe modes and checks each actual bracket and late-operation refusal (`NativeOtherLlamaQuitSelfTest.swift:110–120, 181–204, 260–308, 325–362`). Those fixture inputs are not a simultaneous full owner run.

## Producer and cancellation contracts

- **S1 formatter/runtime.** `S1MiniFormatter.format` races normalize against its timeout using a throwing task group, cancels the other child after the first result, and falls back on error (`S1MiniFormatter.swift:40–76`). The runtime actor checks termination/cancellation at admitted entry and after load; `finishTermination` queues `closeForTermination` on that same actor, which sets the flag and frees its context/model (`129–163, 237–277`). The decode calls inside `performNormalize` are synchronous native brackets (`187–231`), so task cancellation alone is not proof of an interrupted C call. Actor completion/teardown order, not a guessed abort, must be measured. The frozen S1+Cocoa proposal targets this path; its copied-source replay is not a native verdict.
- **NotesService and model runtime.** `NotesService.beginTermination` sets its MainActor admission flag, snapshots the existing task map, and cancels those exact tasks (`NotesService.swift:75–85`). `summarize` owns a per-meeting task and refuses after closure; `generate` checks termination/cancellation across provider selection, context, and before saving notes (`132–197, 324–372`). The model actor's `beginTermination` marks closed, captures/cancels its load task and refuses queued reservations; `finishTermination` joins loading, obtains the same native reservation, requires no active operations/load task, then calls `shutdownNow` (`NotesModelRuntime.swift:187–217`). Generation checks cancellation/admission at scheduler checkpoints and between tokens (`971–987, 1049–1072`); native decode itself is synchronous. This preserves native ownership until return, but source inspection does not time or prove every live caller's close/exit boundary.
- **Other llama owners.** `EmbeddingRuntime.finishTermination` requests an out-of-actor stop and then queues actor close; batches inspect that stop between passages, not inside `llama_encode`/`llama_decode` (`EmbeddingRuntime.swift:80–93, 150–190`). `InstalledModelLibrary.beginTermination` captures/cancels its lazy probe; `finishTermination` joins it (`InstalledModelLibrary.swift:451–465`). `LlamaBackend.beginTermination` closes later native probe admission; `initialize` checks that gate around its MainActor settings hop. It deliberately does not call process-wide `llama_backend_free` (`LlamaBackend.swift:22–42, 59–63`). These are distinct owners and gates, not a single cancellation token.

## Exact remaining qualification

1. **Entry-to-close window.** Current delegate closes NotesService/library synchronously but begins Notes runtime, S1, embedding and backend closure only after assigning the MainActor task (`NextNotesApp.swift:9654–9708`). The source therefore does not establish that every one of those actors refuses a new call *at the moment AppKit accepts the first quit request*. The S1/embedding/Notes actor serializes actual native work, so this is an admission/latency question, not evidence of a use-after-free. A native regression must bracket quit entry, any late actual producer call, native return and final reply for the same owner. The frozen owner fixtures measure separate paths; no simultaneous shared-owner result is in this audit.
2. **Notes coverage boundary.** The Notes native fixture proves only its injected isolated summarize task and model. It does not exercise the shared runtime's concurrent Agent voice/prewarm/load, a pressure shutdown, a loaded installed-library probe, or a simultaneously active S1/embedding owner. The producer-level question is whether each actual work handle/native reservation is closed and drained before the *real* final reply, with no post-close native entry. A source-only callback or an isolated helper check cannot answer that larger question.
3. **Process exit boundary.** The backend close is probe admission, not backend destruction, and `applicationWillTerminate` cannot join any native owner. The AppKit path's final reply must be observed after actual native returns; SIGTERM/forced exit remains outside this contract. The frozen S1, direct33 and independent Pocket57 patches still require their own original/fixed native qualification and ordinary-build checks. `late19` and combined Kokoro remain held.

No new fix is proposed from this audit. The finite source trace supports the next native measurements and preserves the existing one-reply, one-owner-drain design without adding a waiter or serial gate to user work.
