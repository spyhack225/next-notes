It produces a separate static detail file for every approved run and removes revoked generated reports. It never reads raw report contents or copies raw provenance. Legacy approved records receive a report from their already-reviewed scope, summary, environment, metrics and limits. Thirty-nine existing records receive reviewed narrative and optional source/runner links; original measurements and raw reports are retained. New public fields are covered by publication review. See `Benchmarks/FORMAT.md` and schema.

Vite imports detail files on demand. The report renders findings, all measurement boundaries/sample counts/aggregations, method, environment and limitations on the website. An optional GitHub link is secondary evidence, not a prerequisite to understand the result. Downloaded JSON is the reviewed result/comparison only. A report-load failure leaves index measurements readable and offers reloading the same report. Browser failure injection reproduced a cached failed import that remained failed after a simple in-document retry; the fixed action starts a fresh document instead of repeating the rejected module. The main lazy route has a reload boundary.
