# SB-01a — verified existing-file reuse foundation (2026-09-30)

Status: bounded source implementation, isolated red/green fixtures and integrated artifact checks complete. Parent SB-01 remains incomplete.

## Confirmed producer failure

`ModelDownloader.download(RemoteFile)` returned success as soon as the destination had the expected length. It did not check the trusted SHA-256 on that branch. `ModelLibraryStore.run` then probed and registered the file. A same-name, same-length substituted file could therefore be reported as installed even though it was not the requested artifact. The installed manifest also discarded the Hub digest, so it had no persisted checked-byte proof for alias reuse.

The original regression uses three actual bytes: trusted SHA-256 for `abc`, with `abd` on disk at the requested destination. It calls the real downloader against a deliberately unreachable loopback URL; successful reuse or integrity rejection must finish before any fetch. The old source returned success. The new source throws `invalidChecksum` and preserves the existing file.

## Bounded change

The existing downloader verifies a matching-size destination before reuse. The original `Void` API remains, including existing resume task inference; `downloadVerified` runs the same transfer and returns its verification proof to the library producer. A corrupt complete partial is still deleted, while an existing installed destination is preserved on verification failure.

`VerifiedModelArtifact` records the actual checked digest, bytes and a file stamp. Verification checks the stamp both before and after hashing; a later replacement/modification invalidates reuse without hashing model weights on a user's turn. The producer rechecks the stamp through the actual `InstalledModelLibrary.addVerifiedDownload` recording boundary before a row is written or any post-download trial/switch/delete policy runs. Stale nonnil proof throws an integrity error; it is never downgraded silently to an unverified success. Missing trusted digest yields no proof. Older manifest rows decode with nil proof and are never silently promoted based on their basename, family, length, quantization label or expected metadata.

The library exposes exact trusted digest/size/current-proof reuse for runnable, non-auxiliary files. The existing download producer can reuse the original row/ID/path before fetching; it does not add duplicate rows, copy files, create another downloader or rewrite a role. Existing explicit post-download choice/trial policy remains in charge of any requested switch.

No model recommendation, stored user choice, runtime, cleanup formatter, default, cloud permission or module setting changed. No model file was downloaded/copied or hashed. Only tiny disposable fixtures were used.
