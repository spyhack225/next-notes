## Small proposal through the existing seam

Extend only anchors to consider retained commitments as evidence locations, keeping existing candidate/action handling intact. Build one temporary exact lookup over the already-filtered speech, keyed by original text trimmed only at the edges, source and displayed speaker using the same speakerNames mapping. Retain a unique source row's finite nonnegative start; mark repeated identical keys ambiguous. Admit a commitment only when its source, quoted text and known displayed speaker match exactly one original speech occurrence. Nil/unresolvable speaker or changed text refuses; a roster alias does not supply a voice binding. Pass the existing meeting speakerNames at the existing proposals anchor call, defaulting empty for existing callers. This is a local lookup, not a new persistent index/store/channel.

Feed these starts into the unchanged whole-window selector. Keep each utterance's original text, ID, time, source, speaker and command exclusion in its original input domain. Render the unchanged selected transcript; retain original interleaving and chronology. Never merge system fragments into a new utterance, infer a shared far speaker, fabricate a combined quotation, or accept an antecedent as the required primary. A complete neighborhood gives a reader context; it does not establish a complete semantic utterance or prove a commitment.

No commitment becomes candidateActions/actionItems, no commitment triggers live cards/planning, and no new model call, retry, timer, queue or await is added. The existing review evaluates meaning and exact evidence; its permissions and arguments remain unchanged. A false positive cheap commitment may locate speech, but never acquires action authority. Source/speaker-keyed exact location avoids text similarity silently borrowing another speaker's evidence. The inherited structured-item text-only dedup can already lose distinct speakers' equal words; that separate producer policy/regression remains open and is not bundled here.
