# Voice Settings, round two

Source baseline: `8097108a` with the legacy Settings consumer. The same source-contract fixture also reads the rebased round-one UI at `3fa4196e`, then the current tree. Exact source hashes and verdicts are in `wiring-red.log`, `wiring-rebased-red.log` and `wiring-green.log`. The checks are source evidence, not physical UI interaction. The backend is unchanged.

The native fixture `--selftest-voice-settings` invokes the actual Section selection/Retry callbacks and the actual Settings preference writer, speech failure owner, preparation owners and file consumer. Cached readiness and counted PCM replace hardware playback; native model initialize/warm and file PCM production are substituted. It verifies cached-ready playback failure recovery for both engines, stale selection/Retry refusal after Pocket -> Kokoro -> Pocket, unavailable Kokoro refusal, and cold load failure -> preparing -> ready through the existing Pocket/Kokoro preparation tasks. No model download, native speech or click-through is claimed.

`run-batch.py` runs inside one `RELAY_ID=claude2-voice-settings-ui ../heavy.sh` slot: one debug build, focused native flags and the offscreen preview. It preserves each process exit and exact root marker in `checks.json`; an OK assertion marker followed by a crash is failed. `build-pin.json` pins the binary and every source file, and `built-source.patch` records the tracked delta at build time. The added native fixture is pinned by its source hash. Temporary output and this agent's scratch are removed in `finally`, with evidence in `cleanup.json`.

`shots/` contains both engines' ready, preparing, absent and failed states, Pocket's possible numeric progress, selected Kokoro on an unsupported OS, and the written-answer lines. Preview selection is an authored drawing value; it never writes the owner's preferences. The preview flag enters the existing isolated SelfTest environment. PNGs are offscreen renderings, not live UI/download/playback acceptance.
