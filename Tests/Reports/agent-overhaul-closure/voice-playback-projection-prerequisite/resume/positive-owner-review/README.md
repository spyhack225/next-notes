The candidate accepts no single immediate cursor as positive playback. This is backend acknowledgement, not proof of audibility, a physical pause endpoint or an entirely fresh completed buffer. A crossing buffer may include earlier frames; only its positive suffix beyond the conservative checkpoint is represented. Future node host timestamps are never equated to wall time. Two advancing observations alone are also insufficient: the later native played-back callback and exact current owner are required. Receipt state is a few fields on the existing player/synth/output; no store, channel, PCM queue, timer, model pass, task, or foreground await is introduced.
